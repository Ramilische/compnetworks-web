# Проект по компьютерным сетям

Веб-версия этого проекта - фронт на React, бэк на FastAPI

Это графическое приложение для решения задачи проектирования компьютерной сети

Задача решается в несколько этапов, некоторые из них:
1. Определение начальных параметров (NetworkDesignForm), построение топологии
2. Построение маршрутов
3. Расчет пропускной способности в каналах
4. Расчет задержки в узлах
5. Оценка проделанной работы по критериям - цена, задержка и т.д.
